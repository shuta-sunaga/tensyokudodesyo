ChatGPT（チャッピー）職務経歴書プロンプト10選｜コピペ用

履歴書の書き方 2026年09月17日
「職務経歴書を書こうとしても、何年も同じ仕事をしてきただけで書くことが思いつかない」——転職活動で最初に手が止まるのが職務経歴書です。そこで使えるのが、SNSで「チャッピー」と呼ばれているChatGPTです。

ChatGPTは、あなたに質問しながら経歴を聞き出し、実績を数字に直し、求人票に合わせた職務要約や自己PRまで下書きしてくれます。ただし「職務経歴書を書いて」とだけ頼むと、どこかで見たような文章が返ってきて、かえって書類選考で埋もれます。差がつくのはプロンプト（指示文）の書き方です。

この記事では、職務経歴書づくりに特化したコピペ用プロンプト10本を、使う順番・出力例・追加の指示つきで紹介します。製造業の現場経験を例に、経歴の棚卸しから提出前チェックまで、3日で1社分を仕上げる手順としてまとめました。

目次

1. チャッピーで職務経歴書を作る前に｜得意なこと・苦手なこと

　中途採用の書類選考の通過率は、一般に30%前後と言われます。採用担当者が1通の職務経歴書を読む時間は1〜3分ほどで、冒頭の職務要約と実績の数字で「会ってみたいか」がほぼ決まります。つまり職務経歴書は、文章のうまさよりも「何を・どの規模で・どれだけ改善したか」がすぐ読み取れるかの勝負です。

　ChatGPTが得意なのは次の3つです。

  • 聞き出す：質問を重ねて、自分では当たり前すぎて書かなかった経験を掘り起こす
  • 整える：箇条書きのメモを、職務要約・職務経歴・自己PRの形式に並べ替える
  • 照らし合わせる：求人票の要件と経歴を突き合わせ、アピールが足りない所を指摘する

　一方で、あなたの実績の数字を知っているのはあなただけです。ChatGPTは数字がないと、もっともらしい数字を補ってしまうことがあります。この記事のプロンプトには、すべて「材料にない事実を足さない」という条件を入れています。職務経歴書の基本構成は次の記事で解説しています。

　関連記事：AIで差がつく職務経歴書の作り方〜ChatGPTを使った自己PR・志望動機の磨き方

2. 先に用意する材料テンプレート｜10本すべてで使い回す

　プロンプトの出来は渡す材料で決まります。次の4つを1枚のメモにまとめ、各プロンプトの【材料】に貼り付けてください。数字が分からない項目は「不明」と書けば、プロンプト1で聞き出してくれます。

材料テンプレート（この記事のプロンプト全部で使い回します）

【応募先の求人票】
（「仕事内容」「必須要件」「歓迎要件」「求める人物像」を貼り付け。社名は伏せてOK）

【職歴（新しい順）】
・食品メーカーA社／製造部 製造オペレーター→ラインリーダー／2019年4月〜現在（7年）
　担当：パン製造ライン2本、部下12名、シフト作成、新人教育
　実績：不良率1.8%→0.9%、段取り替え40分→25分、不明
・電子部品メーカーB社（派遣）／検査工程／2016年4月〜2018年8月

【資格・スキル】
フォークリフト運転技能者、QC検定3級、Excel（関数・グラフ）

【転職で実現したいこと】
現場経験を活かして生産管理・品質管理の仕事に就きたい

　ポイントは、実績欄に「不明」があってもよいことです。空欄のまま自分で考え込むより、ChatGPTに質問させたほうが早く数字が集まります。社名や個人名は伏せ字で構いません（第7章Q3）。

3. コピペ用プロンプト10本｜出力例と追加の指示つき

　10本は「聞き出す → 骨組みを作る → 中身を磨く → 応募先に合わせる → 仕上げる」の順に並んでいます。

プロンプト1：インタビュー形式で経歴を棚卸しする

プロンプト1：経歴の棚卸しインタビュー

あなたは製造業に詳しいキャリアアドバイザーです。職務経歴書を作るために、私の経歴をインタビューしてください。ルールは次のとおりです。
1. 質問は1回に1問だけ。私が答えるまで次に進まない
2. 「担当業務」「工夫したこと」「数字で表せる結果」「周りからの評価」の順に聞く
3. 私が「特にない」「覚えていない」と答えたら、思い出しやすいように具体的な場面の例を出して聞き直す
4. 15問ほど聞いたら、聞き出した内容を箇条書きでまとめる

【材料】
（テンプレートを貼り付け）

　出力例（抜粋）：「不良率を下げたとのことですが、そのとき一番多かった不良の種類は何でしたか。たとえば焼きムラ、異物、重量不足などです」のように、答えやすい選択肢を添えて聞いてくれます。

　追加の指示：「まとめのうち、応募先の求人票で評価されそうな経験に★をつけてください」。★の数が少ない職歴は、職務経歴書で短く書いて構いません。

プロンプト2：職務要約を3パターン作る

プロンプト2：職務要約の作成

以下の材料をもとに、職務経歴書の冒頭に置く「職務要約」を3パターン作ってください。条件は「各200字以内」「経験年数・職種・規模（人数や担当ライン数）を1文目に入れる」「代表的な実績を数字で1つ入れる」「最後の1文を応募職種で活かせることにする」「材料にない事実は足さない」です。3パターンは①実績重視、②マネジメント重視、③応募職種との接点重視とし、採用担当者が最も読み進めたくなるものを1つ選んで理由を添えてください。

【材料】
（テンプレートを貼り付け）

　出力例（抜粋）：「③食品メーカーでパン製造ライン2本のラインリーダーを7年務め、部下12名の管理と工程改善に携わってきました。不良の原因を工程ごとに記録・分析し、不良率を1.8%から0.9%に半減させた経験を、生産管理として計画段階から活かしたいと考えています」。

　追加の指示：「③を150字に縮めてください」。応募フォームの入力欄に文字数制限がある場合にそのまま使えます。職務要約の型は次の記事にまとまっています。

プロンプト3：職務経歴欄を「業務」と「実績」に分けて整形する

プロンプト3：職務経歴欄の整形

以下の職歴を、職務経歴書の「職務経歴」欄に整形してください。会社ごとに「期間／会社概要（業種・従業員規模）／所属・役職」の見出しを立て、その下を【担当業務】（箇条書き4〜6行）と【実績・取り組み】（箇条書き3行、各行に数字を入れる）に分けます。新しい職歴から並べる逆編年体にし、応募職種と関係の薄い職歴は3行以内に圧縮してください。数字が材料にない行は「（数値要確認）」と書き、推測で埋めないでください。

【材料】
（テンプレートを貼り付け）

　出力例（抜粋）：「【実績・取り組み】・不良の発生工程を日報で記録する仕組みを作り、不良率を1.8%→0.9%に改善（2022年度）　・段取り替えの手順を標準化し、1回あたり40分→25分に短縮（数値要確認：年間の削減時間）」。

　追加の指示：「（数値要確認）の項目について、私が社内で確認できそうな資料や、概算で出す計算式を教えてください」。

プロンプト4：数字がない仕事を数字で書き直す

プロンプト4：実績の数値化

以下は数字が入っていない実績の文です。1文ずつ「量（件数・人数・台数）」「頻度（毎日・月○回）」「期間（何か月で）」「比較（前後の変化）」「範囲（何ライン・何拠点）」のどれで数字を入れられるかを示し、私に確認すべき質問を1つずつ出してください。私が答えたら、その数字を使って書き直してください。

【数字がない文】
・新人教育を担当した
・シフト作成を担当した
・設備トラブルに対応した
【材料】
（テンプレートを貼り付け）

　出力例（抜粋）：「新人教育→量と期間で表せます。質問：これまで何名を教え、1人が独り立ちするまで何週間かかりましたか？」。答えると「新人18名の教育を担当し、作業手順書を作り直して独り立ちまでの期間を6週間から4週間に短縮」のように書き直されます。

　追加の指示：「書き直した文で、採用担当者が『本当？』と疑いそうな箇所を指摘してください」。面接で聞かれても説明できる数字だけを残します。実績の書き方の基本は次の記事で解説しています。

プロンプト5：「活かせる経験・知識・スキル」欄を作る

プロンプト5：活かせるスキル欄

求人票の必須要件・歓迎要件を1つずつ取り出し、私の経験の中でそれを満たす根拠を探してください。結果を「要件／私の経験での根拠／根拠の強さ（◎○△×）」の表にし、◎と○の項目だけを使って職務経歴書の「活かせる経験・知識・スキル」欄を箇条書き5行で作ってください。資格はPCスキルと分けて末尾に並べてください。

【材料】
（テンプレートを貼り付け）

　出力例（抜粋）：「要件：生産計画の立案経験／根拠：日々のシフト作成で人員配置と生産数を調整／強さ：○」「要件：生産管理システムの使用経験／根拠：なし／強さ：×」。×の項目は、無理に書かず面接で学ぶ姿勢を伝える材料にします。

プロンプト6：求人票に合わせた自己PRを作る

プロンプト6：自己PRの作成

求人票の「求める人物像」から、この企業が最も重視していそうな強みを1つ選び、理由を説明してください。そのうえで、その強みを証明する私のエピソードを1つ選び、自己PRを300字以内で書いてください。構成は「強み（1文）→根拠となるエピソード（状況・行動・結果）→入社後の活かし方（1文）」です。「コミュニケーション能力」「責任感」のような抽象語だけで強みを言い切らず、行動が見える言葉に置き換えてください。

【材料】
（テンプレートを貼り付け）

　出力例（抜粋）：「私の強みは、現場の数字を記録して原因を突き止めるまで粘ることです。不良が月40件ほど出ていたラインで、工程ごとの発生件数を3か月記録し、発酵室の温度ムラが主因だと特定しました」。

プロンプト7：求人票とのズレ診断｜抜けているキーワードを探す

プロンプト7：マッチ度診断

あなたはこの求人の書類選考を担当する人事です。以下の職務経歴書（下書き）を求人票と照らし合わせ、①マッチ度を100点満点で採点、②求人票にあるのに職務経歴書に出てこない言葉を最大10個、③その言葉を事実の範囲で自然に入れられる箇所と書き換え案、④書類選考で落とすとしたらその理由、を出してください。事実を足す書き換えは提案しないでください。

【職務経歴書（下書き）】

【材料】

プロンプト8：未経験職種に通じる経験に言い換える

プロンプト8：異職種への言い換え

プロンプト10：採用担当者の目で提出前チェックをする

プロンプト10：提出前の最終チェック

以下の職務経歴書を提出前に点検してください。チェック項目は①誤字脱字・表記ゆれ（西暦と和暦、全角と半角の数字など）、②職務要約・職務経歴・自己PRの間で数字や期間が食い違っていないか、③「〜に貢献」「〜を推進」など中身のない言い回し、④AIが書いたように見える硬い表現や同じ語尾の連続、⑤A4用紙2枚に収まる分量か、の5つです。問題点を一覧にし、修正後の全文を出してください。修正箇所は【】で囲んでください。

4. 出力をWord・Googleドキュメントの書式に整える

　ChatGPTの出力は文章としては完成していても、そのままでは職務経歴書の体裁になりません。次の手順で整えます。

  • 書式を決める：A4縦、余白上下左右20mm前後、本文10.5〜11pt、見出し12pt。全体で2枚、多くても3枚
  • 順番を並べる：タイトル・日付・氏名 → 職務要約 → 活かせる経験・知識・スキル → 職務経歴（逆編年体）→ 資格 → 自己PR
  • 記号をそろえる：箇条書きの「・」と「■」、期間の「〜」の表記を全体で統一する
  • PDFで保存する：ファイル名は「職務経歴書_氏名_20260917.pdf」のように日付を入れる

　枚数の目安は次の記事で解説しています。

　関連記事：職務経歴書は何枚が正解？2枚に収めるコツ

5. やってはいけない2つの使い方

NG1：出力をそのまま全社に使い回す

　同じ職務経歴書を10社に出すより、職務要約と自己PRだけでも応募先ごとに差し替えたほうが通過率は上がります。プロンプト2・6・7は、応募先ごとに求人票を貼り替えて回し直してください。

NG2：材料にない実績や肩書きを足させる

　「もっと印象的にして」と頼むと、ChatGPTは存在しない数字や役職を補うことがあります。経歴詐称と判断されると内定取り消しの理由になり得るため、出力のたびに材料にない数字がないか確認してください。

6. 3日で1社分を仕上げるスケジュール

　1日60〜90分を想定した目安です。

  • 1日目：材料テンプレートを埋める → プロンプト1で棚卸し → プロンプト4で数字を集める
  • 2日目：プロンプト2・3・5で骨組みを作る → プロンプト6で自己PR → 必要に応じてプロンプト8・9
  • 3日目：プロンプト7でズレ診断 → 修正 → プロンプト10で最終チェック → Wordで整えてPDF保存

　2社目以降は、材料テンプレートの求人票だけを差し替え、3日目の作業を行えば1時間ほどで仕上がります。

7. よくある疑問Q&A

Q1. 無料プランで足りますか？

　10本すべて無料プランで動きます。ただし利用回数に上限があり、プロンプト1のような長いやりとりは途中で制限にかかることがあります。職務経歴書を作る数日だけ有料プラン（月額3,000円前後）にする使い方が現実的です。

Q2. ClaudeやGeminiでも同じプロンプトが使えますか？

　使えます。Claudeは長い文章の自然さに強く、GeminiはGoogleドキュメントとの連携が便利です。Claudeで職務経歴書を作る場合の違いは次の記事で整理しています。

　関連記事：Claudeで職務経歴書を作る｜ChatGPTとの違い

Q3. 経歴や社名を入力して個人情報は大丈夫ですか？

　氏名・社名・取引先名・製品名は伏せ字にしてください。ChatGPTの設定にある「データコントロール」で「すべての人のためにモデルを改善する」をオフにすると、入力内容が学習に使われなくなります。業種と規模（「従業員300名の食品メーカー」など）が分かれば、精度は落ちません。

Q4. AIで作った職務経歴書だと見抜かれて不利になりませんか？

　採用担当者が気にするのは「AIを使ったか」より「本人の経験が具体的に書かれているか」です。材料に自分の数字と場面が入っていれば、中身はあなたの経歴です。
